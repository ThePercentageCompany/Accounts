# Workspace visual direction

Inspired by giga.ai's warm editorial presentation: ivory canvas, charcoal type,
orange accents, generous whitespace and clear hierarchy. TPC branding, content,
permissions and workflows remain specific to this product.

`AppTheme` supplies both appearances across the app: cards, tables, forms,
dialogs, menus, sheets, notifications, navigation and button states. Existing
color constant names are retained for compatibility. Primary action text uses
a darker burnt orange for contrast; bright orange is reserved for decoration.
Status colors retain their semantic meaning.

The landing page introduces a responsive editorial hero and an explicitly
illustrative workspace preview. Its entrance animation respects reduced motion.
Workspace navigation uses outlined icons and a compact percentage brand mark.
Dashboard charts use the same warm accent palette. Native dialogs and dense
record tables inherit the visual system without changing their functionality.

Use shared theme tokens for new screens. Avoid navy/teal hero gradients, extra
card shadows, oversized icon badges and independent local color systems.
